# 分级源清单（机器学习 / LLM / Agent / 强化学习）

检索入口白名单。命中任何来源后必须回源访问原文；转载媒体一律降级为线索。

## 一、同行评议期刊（新发表首选）

- **JMLR**（机器学习理论旗舰，全 OA）
- **TMLR**（Transactions on Machine Learning Research，OpenReview 体系）
- **JAIR**（Journal of Artificial Intelligence Research，全 OA）
- **IEEE TPAMI**（模式识别与机器视觉）
- **Artificial Intelligence**（Elsevier，AI 老牌旗舰）
- **Machine Learning**（Springer）
- **Nature Machine Intelligence**、**Nature Computational Science**
- **Neural Computation**（神经网络理论基础）

## 二、预印本服务器（标注「预印本」）

- **arXiv cs.LG**（机器学习，本领域主阵地）
- **arXiv cs.AI**（人工智能）
- **arXiv cs.CL**（计算语言学 / LLM）
- **OpenReview**（NeurIPS / ICLR / COLM 等会议的公开评审与投稿版本，录用前标注「预印本」）

## 三、官方与机构（企业声明一律标注「单一来源」）

**会议与评审（可信度高，属机构数据而非营销）**
- NeurIPS / ICML / ICLR / ACL / AAAI / COLM 官网（录用论文、Best Paper、公告）
- PMLR（proceedings.mlr.press，会议论文集）
- OpenReview（openreview.net，公开评审）

**评测与数据集**
- Papers With Code（论文-代码-基准关联）
- Hugging Face Papers 与模型页
- 各基准官方站（如 SWE-bench、GAIA、HumanEval 等）

**企业研究主体（仅可公开验证的产出，标注「单一来源」）**
- OpenAI、Google DeepMind、Anthropic、Meta AI、Mistral AI、xAI、Microsoft Research

**资助机构与计划**
- NSF / 国内基金委相关 AI 资助计划官方页

## 四、权威媒体（仅背景交叉，不作主源）

- MIT Technology Review
- Quanta Magazine
- The Gradient
- Nature News（新闻栏，区别于论文）

## 五、会议与届次

- NeurIPS / ICML / ICLR / ACL / AAAI / COLM（CCF-A 会议）
- 各会议录用公告、Best Paper、Workshop 动态

## 六、排除项

- 社交媒体、自媒体、营销稿、行业融资消息（除非作为「传播现象」的研究对象）
- 无同行评议亦无预印本的纯博客声明（个人博客仅在前次已核实作者身份时可用，且标注）
- 预测市场、股票行情类信息（本监测不做投资分析）
