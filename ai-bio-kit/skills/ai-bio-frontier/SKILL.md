# 机器学习 / LLM / Agent 前沿监测

本技能是领域数据层，方法论规则以第二节为准。

## 一、核心资产（references/ 目录）

| 文件 | 用途 |
|---|---|
| `sources.md` | 分级源清单——检索入口白名单 |
| `queries.md` | 七域固定检索查询组——日报的检索骨架 |
| `milestones.md` | 里程碑锚点——判断「新进展是否真的新」的基准 |
| `digest-template.md` | 日报 Markdown 结构模板 |

## 二、规则摘要（方法论详见 rigorous-research）

1. 来源四级：同行评议 > 预印本（标注）> 机构公告（企业声明一律标注「单一来源」）> 权威媒体（仅背景交叉）
2. 模型能力声明核对三要素：指标 / 测试集 / 年份，缺项明示
3. 重大声明双源交叉验证，单源进待核实清单
4. 三类标注：事实（常规）、预印本与单一来源（标注）、「分析：」（推断）
5. 命中后必须回源访问原文；转载媒体只作线索

## 三、日报工作流（五步）

1. **防重复**：目标目录若已存在当日文件（`YYYY-MM-DD.html`），跳过本次任务
2. **检索**：按 `queries.md` 七域查询组逐组执行，窗口默认最近 3 天；每组至少 1 条通用查询 + 1 条限定来源查询；另查横向查询（CCF-A 会议动态、重点机构公告）
3. **核对分级**：回源访问、来源分级、三要素核对、双源验证
4. **产出**：按 `digest-template.md` 写 Markdown 日报（只保留有效阅读内容，查询与排除过程不写入正文），再用 `python3 scripts/digest2html.py <日报.md> -o <工作台目录>/data/frontier/YYYY-MM-DD.html` 转成 HTML（工作台根目录即 server.py 所在目录）；无重大进展的日子照常产出并如实写明
5. **HTML 校验**：脚本自带零改动校验，输出 FAIL 必须修复重跑

## 四、领域判定基线（分析性判断）

- 模型性能声明必须核对「指标 / 测试集 / 年份」三要素；基准分数不等于真实效果
- 缩放定律驱动能力增长，但收益递减、数据墙与推理成本上升是持续争论
- 基准饱和普遍存在：旧基准被刷爆后不再能区分模型
- Agent 可靠性（长程任务成功率、评测可复现性）仍是开放问题
- 以上为分析性判断（非事实），新证据出现时应在日报「里程碑对照」区讨论，而非默认沿用

## 五、周报变体

每周最后一天可将 7 份日报合并为周报：去重、按七域重组、对照 `milestones.md` 写「本周是否改变锚点格局」综述。格式仍用 `digest-template.md`，标题改「周报」。
